STABLE FARE SLABS

No daily fare fluctuations.

Operating costs can change continuously, but passenger fares should change only when a statistically justified slab threshold is reached.

03

Test

04

FAIRNESS ENGINE

Sustainable for drivers. Affordable for passengers.
